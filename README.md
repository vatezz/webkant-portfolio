# WEBKANT Portfolio

Statische Portfolio- und Verkaufswebsite für WEBKANT.

## Technologien

HTML, CSS und Vanilla JavaScript. Es werden keine Frameworks, externen Bibliotheken, Tracker oder externen Requests verwendet.

## Produktionsstruktur

- `index.html` – Seite und SEO-Metadaten
- `style.css` – responsive Layouts und Animationen
- `script.js` – Navigation, Project Viewer, Dialoge und Formular-Demo
- `assets/logo/` – WEBKANT-Logo-Assets
- `assets/projects/` – Desktop-Screenshots von MainGlanz, Farbwerk und GRÜNFORM

## Lokal starten

Die Dateien können mit jedem statischen Webserver geöffnet werden.

## Kontaktformular

Das Formular hat bewusst kein Backend: Es verhindert die Übertragung, speichert keine Daten und zeigt nach einer gültigen Eingabe einen Hinweis. Ein datenschutzkonformes Formular-Backend kann später in `script.js` angeschlossen werden.

## Veröffentlichung

Domain und Hosting werden separat eingerichtet. Impressum und Datenschutzerklärung müssen vor einer öffentlichen Veröffentlichung mit geprüften, echten Angaben ergänzt werden.
